Colophon

This site is built with Overprint. The entries are Markdown files in a folder, and the look of the whole thing is four lines in overprint.yml:

theme:
  mode: light
  accent: "#C2410C"
  font: sans
  background: "#F5EBDC"

Light mode, a warm cream page instead of the white it would otherwise give me, the system sans stack, and one burnt orange for post titles and links. Nothing else on the page is colored.

Why each of those is what it is: Four knobs and a cream page. Why I stopped wanting a stylesheet: There is no stylesheet to open. I set the block in February and have not opened it since.

Photographs are mine, taken on a phone in the bay, usually with the door rolled up for the light. Type is whatever your machine calls its system sans. Hosting is GitHub Pages.
